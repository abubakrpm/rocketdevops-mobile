# Demo video script (about 90 seconds)

Follows the spec's demo flow: Home, resume the Docker lab, complete an objective, answer quiz
questions, then show live progress and an unlocked achievement on Profile.

## Before recording

- Settings: Light theme, Medium text, quiz timer **off**. Turn on Do Not Disturb.
- Settings > Reset progress > tick "Also forget the name" > Reset. On the Welcome screen type a name.
- In the Docker track, finish everything in module 1 (lesson "Images and containers", lab "Download your
  first image", "Images quiz") and both lessons of module 2. The Continue card shows the next unfinished
  item, so Home now says "Continue, Docker: Run your first container" with **Resume lab**.
- Record with the phone's built-in **Screen recorder** (quick settings). Speak slowly, or record the
  voice afterwards over the video.

## Script

| Time | On screen | Say |
|---|---|---|
| 0:00 to 0:10 | Home: greeting, streak, Continue card | "This is RocketDevOps, a free app for learning Linux, Git and Docker. It works fully offline." |
| 0:10 to 0:15 | Tap **Resume lab** | "I'll continue the Docker lab where I left off." |
| 0:15 to 0:25 | Lab: type `docker pull nginx`; the first objective turns green | "The terminal is simulated: nothing runs on the phone, but it behaves like the real Docker CLI, and the objectives tick as I work." |
| 0:25 to 0:30 | Open a hint, then close it | "If I'm stuck, there are three levels of hints." |
| 0:30 to 0:40 | Type `docker run -d --name web -p 8080:80 nginx`; the success screen appears | "Lab done." |
| 0:40 to 1:05 | Back on the track, open the "Docker basics" quiz: answer 3 questions, one of them wrong on purpose | "Quizzes give instant feedback. A wrong answer shows the right one and explains why." |
| 1:05 to 1:20 | Profile: metrics, last-7-days chart, achievement "First command" unlocked | "Every lab, quiz and lesson updates my progress, streak and achievements at once. It is all stored on the phone with Room." |
| 1:20 to 1:30 | Cheat sheet: type `logs`, tap copy | "And a searchable cheat sheet of 80 commands. Thanks for watching." |

## After recording

- Trim the start and end in the phone's gallery editor. Keep it under 2 minutes.
- Upload it as an unlisted YouTube video or add it to the GitHub release.
