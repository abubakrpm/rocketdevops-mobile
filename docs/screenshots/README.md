# Screenshots

The main README shows these 8 files. Take them on a real phone and save them here with exactly
these names (PNG). Until they are added, GitHub shows broken-image icons in the README.

| File | Screen | Theme | What should be on screen |
|---|---|---|---|
| `home-light.png` | Home | Light | A streak of 2 or more days, the Continue card with a progress bar |
| `track-light.png` | Docker track | Light | One module Done, one In progress (opened), the rest Locked |
| `lab-light.png` | Lab "Run your first container" | Light | 2 commands typed, one objective green |
| `quiz-light.png` | Any quiz | Light | A question just answered, with the Why card |
| `cheats-light.png` | Cheat sheet | Light | The Docker chip selected |
| `profile-light.png` | Profile | Light | Some labs done, the chart with a few bars, 2 or more achievements unlocked |
| `home-dark.png` | Home | Dark | Same as home-light |
| `lab-dark.png` | Any lab | Dark | A few commands with output |

## How to take them

1. Use a neutral name on the Welcome screen (for example "Ali"), or skip it.
2. Do a little real progress first (2 lessons, 2 labs, 1 quiz) so no screen looks empty.
3. Take each screenshot with **Power + Volume down**, or in Android Studio with the camera button
   of the **Running Devices** window while the phone is connected by USB.
4. Copy them to the laptop (USB cable, or Google Photos), rename them as in the table, and put them
   in this folder (`docs/screenshots/`).
5. Commit and push: `git add docs/screenshots` then `git commit -m "Add screenshots"` then `git push`.

Tip: turn on Do Not Disturb before taking them, so no notifications appear in the status bar.
